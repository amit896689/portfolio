# Amit Kumar Singh — Academic Portfolio

Personal portfolio website of **Amit Kumar Singh**, PhD researcher in Earth Observation
(Sapienza University of Rome / University of Naples Federico II) and Visiting PhD Scholar
at Cornell University. Built with plain HTML + CSS + JS, hosted on GitHub Pages.

## ✨ Features
- Editorial-academic design system (cream / library-green palette, Fraunces + Manrope + JetBrains Mono)
- Light & dark mode with persisted preference and `prefers-color-scheme` detection
- Sections: About, Research Experience, Education, Publications, Skills, Trainings, Achievements, Contact + References
- Institution logo marquee (Wikimedia Commons logos with monogram fallbacks — never a broken image)
- Scroll-reveal animations, scroll-spy navigation, sticky header, mobile menu
- Accessibility: skip link, visible focus states, ≥4.5:1 contrast, `prefers-reduced-motion`, semantic HTML
- Print-friendly stylesheet
